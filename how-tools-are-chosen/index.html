How these tools are chosen

Every tool on coping.tools has to pass four tests.

It has to be usable in a difficult moment

A technique may be sensible on paper and still be useless when someone is overwhelmed.

Instructions are kept short, choices are limited and the first useful action should be easy to reach.

The evidence has to be represented fairly

Some techniques are supported by substantial research. Others are practical adaptations of broader approaches.

We make that distinction.

If research supports the underlying approach but not the exact exercise used here, we say so rather than calling the exercise clinically proven.

It has to earn its place

The internet already contains thousands of coping-skill lists.

We do not add a tool simply because it is familiar.

Each one should have a clear purpose and fit the situation it appears under.

Search should help people find the tools, not change the tools

Pages are written so people looking for coping tools can find them.

That does not mean padding pages with repeated keywords, generic explanations or unnecessary articles.

The person using the tool comes first.

Ongoing review

Tools are checked for practical use during distress, evidence and limits, misleading claims, repetitive wording, phone readability and search usefulness.

The evidence behind each intervention is revisited periodically. New systematic reviews, clinical guidance and relevant research are checked against what the page currently says.

Newer does not automatically mean better. The quality, relevance and practical usefulness of the evidence matter. When stronger or more useful evidence changes what belongs here, or changes how a tool's limits should be described, the page is updated.

The review date shown on each tool page records when its evidence and guidance were last checked.

coping.tools is not intended to diagnose or treat a mental-health condition.

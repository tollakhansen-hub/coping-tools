Privacy

coping.tools is designed to collect as little personal information as possible.

This static site does not include accounts, contact forms, advertising or behavioural profiling.

The live site currently includes Cloudflare's Web Analytics/RUM performance beacon, injected by the hosting layer. Cloudflare states that its Web Analytics beacon does not use cookies or browser storage for tracking. It collects page-view and performance information. Cloudflare processes your IP address and requested URL to serve and protect the site. This is separate from the install counter, which stores only event names and aggregate totals.

To understand whether the optional app-install feature is useful, coping.tools keeps anonymous aggregate counts of three events: pressing “Install app”, accepting the browser's install prompt, and the browser confirming installation. These counters do not store IP addresses, countries, device or browser identifiers, account data, or which pages a visitor viewed. Access to aggregate install totals is intended for the site maintainer, not a public statistics page.

Each coping page also has an optional “Was this page useful?” question. When you choose Yes or No, only an aggregate count for that page, answer and UTC date is stored. No names, diagnoses, personal comments, IP addresses, device identifiers or individual voting histories are kept in this feedback database. Only the site maintainer can access the aggregate feedback report. The answers are not a measure of clinical effectiveness.

To avoid accidental repeat votes on the same page during one tab session, your browser stores a small page-specific completion flag in session storage. It stays in your browser and is not transmitted. Each coping page can be answered independently. You can clear the flag by closing the tab or clearing site data.

coping.tools saves copies of its public pages, fonts and other required files in your browser for offline use. This includes all coping routes, rather than only those you visit. These copies stay on your device; API responses are excluded from this offline cache. Offline copies may be older than the live site. You can remove them by clearing this site's browser data.

If privacy-affecting features are added later, this page must be updated before or when those features go live.

Links to research and guidance may take you to external websites. Those websites have their own privacy practices.

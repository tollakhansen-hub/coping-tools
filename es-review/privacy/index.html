Privacidad

coping.tools está diseñado para recopilar la menor cantidad posible de información personal.

Esta web estática no incluye cuentas, formularios de contacto, publicidad ni elaboración de perfiles de comportamiento.

La adaptación al idioma se realiza en el navegador. Si eliges inglés o español en el selector de idioma, esa elección se guarda en el almacenamiento local del navegador para que el sitio la recuerde en futuras visitas; si el almacenamiento local no está disponible, se utiliza el almacenamiento de sesión cuando es posible. Esta preferencia no se incluye en las respuestas de opinión ni en los recuentos de impresión o instalación. Puedes eliminarla borrando los datos de este sitio en el navegador.

La web actualmente incluye la baliza de rendimiento Web Analytics/RUM de Cloudflare, añadida por la plataforma de alojamiento. Cloudflare afirma que su baliza de Web Analytics no utiliza cookies ni el almacenamiento del navegador para el seguimiento. Recopila datos sobre visitas a páginas y rendimiento. Cloudflare procesa tu dirección IP y la URL solicitada para ofrecer y proteger la web. Esto es independiente del contador de instalaciones, que solo guarda nombres de eventos y totales agregados.

Para saber si resulta útil ofrecer la instalación de la aplicación, coping.tools mantiene recuentos agregados y anónimos de las pulsaciones del botón de instalación, las solicitudes del navegador aceptadas, las instalaciones confirmadas por el navegador y la primera apertura de la aplicación instalada en iPhone y iPad. En estos dispositivos, después de registrar la primera apertura desde la pantalla de inicio, la aplicación guarda una marca en el dispositivo para evitar contarla de nuevo. Esa marca permanece en tu dispositivo. Los contadores guardan nombres de eventos y totales; no almacenan direcciones IP, identificadores del dispositivo o del navegador, datos de cuentas ni las páginas que visita cada persona. Solo quien mantiene la web puede consultar los totales.

Cada página de afrontamiento también incluye una pregunta opcional: «¿Te ha resultado útil esta página?». Al elegir «Sí» o «No», solo se guarda un recuento agregado para esa página, respuesta y fecha UTC. Esta base de opiniones no guarda nombres, diagnósticos, comentarios personales, direcciones IP, identificadores de dispositivos ni el historial de respuestas individuales. Solo quien mantiene la web puede consultar el informe agregado. Las respuestas no miden la eficacia clínica.

Cuando pulsas «Imprimir» o «Guardar PDF» en una guía, coping.tools registra un recuento agregado y anónimo para esa guía, acción y fecha UTC. Una solicitud de impresión no confirma que la página se haya impreso; guardar un PDF significa que se ha iniciado una descarga. El contenido de la guía se prepara en tu dispositivo y no se envía al contador. El contador no guarda nombres, direcciones IP, diagnósticos ni historiales de acciones individuales. Solo quien mantiene la web puede ver estos totales.

La página privada de estadísticas utiliza una cookie de inicio de sesión segura y HttpOnly, que caduca a los 30 días o cuando quien mantiene la web cierra sesión. El token de estadísticas solo sirve para iniciar sesión y no se guarda en la página ni en la URL. La página privada está excluida de la caché sin conexión y utiliza una política de navegador independiente para impedir que se ejecute allí la baliza de Cloudflare Web Analytics. Abrir la página privada no envía votos ni eventos de impresión. Los registros generales de solicitudes HTTP de Cloudflare son independientes de las estadísticas de visitas basadas en el navegador.

Para reducir las respuestas repetidas por accidente, el navegador guarda, cuando es posible, una pequeña marca de «respondido» para cada página en el almacenamiento local; si no está disponible, utiliza el almacenamiento de sesión. La marca permanece en tu dispositivo y no se envía a coping.tools; no contiene tu respuesta ni un identificador. Puedes responder por separado en cada página. Normalmente, la marca permanece aunque cierres y vuelvas a abrir el navegador o la aplicación, pero puede no conservarse en la navegación privada o si se restringe el almacenamiento. Puedes eliminarla borrando los datos de esta web. Es una protección del navegador, no una garantía contra respuestas duplicadas.

coping.tools intenta guardar en el navegador copias de las páginas públicas, las fuentes y otros archivos necesarios para poder utilizarlos sin conexión, incluidos los cinco recorridos de afrontamiento. Algunas páginas podrían no estar disponibles sin conexión si no se guardaron correctamente. Las copias permanecen en tu dispositivo; las respuestas de API no se incluyen en esta caché. Las versiones sin conexión pueden estar desactualizadas. Puedes eliminarlas borrando los datos de esta web en el navegador.

Si en el futuro se añaden funciones que afecten a la privacidad, esta página se actualizará antes o cuando se activen.

Los enlaces a investigaciones y orientaciones pueden llevarte a webs externas, que tienen sus propias prácticas de privacidad.
